# Historical Jira run

Results from the first real-data run: 50,855 fixed Apache Jira bugs, one chronological 70/15/15 split. Kept for reference only. That protocol used current field values as inputs, excluded unfixed bugs, trained on outcomes that settled after the test cutoff and shuffled the inner stacking folds, so these numbers are not comparable to `artifacts/jira_temporal/`. See "Real-data check" in the main README.
